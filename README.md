# Voyager for Gemini (Android Xposed 增强模块)

> 专为 Android 端 Gemini 打造的沉浸式功能增强工具，解锁高效对话管理与极致交互体验。

## 💡 灵感来源与参考

本项目灵感来自于著名的 Web 端 AI 增强插件套件项目： 👉 [**voyager-crew/voyager**](https://github.com/voyager-crew/voyager)

感谢原项目在对话管理、时间线导航及公式提取等核心交互理念上的启发。本模块致力于将 `voyager` 在 Web 端的优秀体验移植并重构至 **Android 原生 App + Xposed/LSPosed** 环境下。

## 🌟 核心功能概览

### ⚡ Gemini 额度与刷新时间监控 UI (StatusBar / Bar 样式) [重构核心首发]

- **胶囊悬浮形态**：精致圆角扁平的顶部悬浮栏 (Bar Style)，居中或靠顶自适应排列，与 Android 状态栏无缝融为一体。
- **单行双维度监控 (Row 布局)**：
  - **短期/5h 额度**：显示如 `5h` 模型标签、带绿色指示点（🟩）的百分比微型进度条（如 `9%`）、以及刷新剩余倒计时 `(24m)`。
  - **每周额度**：显示 `每周` 标示、周配额进度条（如 `6%`）、以及刷新倒计时 `(4d3h)`。
- **快捷交互与操作**：
  - **↻ 手动刷新**：带平滑 360° 旋转动效，一键触发网络探测与额度接口主动拉取。
  - **🗗 展开详情**：轻触即弹出完整用量详情弹窗，包含下一次重置精确时间、账号订阅状态（Gemini Advanced / 免费版）及快速跳转。
- **三级数据抓取引擎 (QuotaParser)**：通过 Hook OkHttp / HttpURLConnection 网络响应头（`x-ratelimit-*` / `quota-reset`）及 batchexecute 响应体，自动计算当前时间与重置时间戳的差值动态递减。

### 🔘 智能悬浮交互中心

- **动态视觉设计**：采用 52dp 翡翠绿发光气泡，兼具美观与识别度。
- **无痕悬浮体验**：支持全屏任意位置拖拽，松手即平滑吸附至屏幕边缘；无操作时自动降低透明度淡化，不干扰正常浏览。

### 🔖 会话书签与快捷速递 (新特性)

- **一键极速标星**：无论在实时对话、文件夹还是浮动条中，均可一键将当前重点会话添加为永久书签。
- **即刻直达记录页**：在书签面板中，点击任意书签卡片**一下子即可直接跳转到相对应的完整问答记录页面**，完整呈现提问与 Gemini 回答，支持一键填入输入框续聊与唤起官方跳转。

### 📂 会话分类与历史回溯

- **真实 URL 解析**：精准捕获并收录当前 Gemini 会话的真实链接与标题。
- **三级结构管理**：通过树状文件夹归类历史对话，支持点击条目直接进入该会话的完整问答记录与操作中心，并支持一键加星标。

### 📍 对话时间线与精准跳转

- **提问节点提炼**：实时分析当前聊天内容，自动萃取用户的真实提问作为导航节点。
- **定位高亮指示**：点击节点即可平滑滚动至对应对话位置，并伴有高亮闪烁效果，长文浏览更清晰。

### 💾 高效数据导出与分享

- **标准格式支持**：一键导出包含标准代码高亮渲染的 Markdown 或 JSON 格式文本。
- **系统级集成**：生成文件后即刻唤起系统分享面板，方便保存或跨应用传输。

### 💡 极速提问与模版引擎

- **引用回复**：支持对特定消息进行一键引用，精准针对历史回答进行深入追问。
- **变量模版支持**：内置 Prompt 词库，支持包含 `{{变量}}` 的占位符语法。选中后自动填充并拉起键盘聚焦，大幅提升重复提问效率。

### 📐 数学公式多平台适配

- **多格式一键导出**：完美支持导出 **LaTeX**、**MathML (专为 Microsoft Word 优化)** 及 **Notion** 兼容格式，彻底解决跨软件公式排版难题。

## 🛠️ 环境要求与安装步骤

### 前置要求

1. 设备已获取 Root 权限（如 Magisk, KernelSU, APatch 等）。
2. 已激活 LSPosed 或其他兼容的 Xposed 框架。
3. 设备已安装官方 Gemini Android 客户端。

### 安装指南

1. 下载并安装最新版本的 **Voyager for Gemini** APK。
2. 打开 LSPosed 管理器，启用本模块。
3. 在作用域列表中勾选 **Gemini** 应用。
4. 强制停止并重新启动 Gemini App，即可在界面中看到翡翠绿悬浮球。
